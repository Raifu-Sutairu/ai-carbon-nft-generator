# VITC Project 

A comprehensive platform for carbon credit trading, community governance, and NFT marketplace built on blockchain technology.

## Project Structure

This monorepo contains three main components:

### 📱 Frontend (`/frontend`)
React-based user interface for the carbon credit marketplace and community platform.

### ⛓️ Web3 (`/web3`)
Smart contracts, blockchain services, and Web3 infrastructure for the platform.

### 🤖 AI Service (`/ai-service`)
AI-powered art generation service using Google's Gemini API for carbon credit NFTs.

## Getting Started

Each directory contains its own setup instructions and documentation. Navigate to the specific service you want to work with:

- **Frontend**: See `/frontend/README.md`
- **Web3**: See `/web3/README.md` (coming soon)
